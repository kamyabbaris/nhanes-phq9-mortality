PHQ-9 Depression Severity and All-Cause Mortality

A survey-weighted Cox analysis of NHANES 2005–2018

Full report → Source code (GitHub) →
Headline result: after adjustment for age, sex, race/ethnicity, education, marital status, income, BMI, smoking, diabetes, and cardiovascular disease, PHQ-9 depression severity shows a largely monotonic dose-response relationship with all-cause mortality risk (n = 22,471; 2,108 deaths).
